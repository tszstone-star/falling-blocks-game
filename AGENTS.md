# Working Rules

- Keep solutions simple and make the smallest sufficient change.
- Avoid new dependencies; use the existing HTML/CSS/vanilla JavaScript stack.
- Do not add features outside the requested task scope.
- Separate game logic in `src/game/` from UI rendering in `src/ui/`.
- Update or add meaningful tests when game logic changes.
- Run `npm test` before declaring work complete.
- Review the current state first and avoid unrelated edits.
- Do not create a Git commit unless explicitly requested.
- Do not use network access unless explicitly authorized.
- AI suggests; the human decides major tradeoffs and scope changes.
