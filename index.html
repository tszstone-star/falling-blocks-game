    Keyboard controls

    Use on-screen controls or keyboard shortcuts while the game page is active.

    • ← →Move

    • ↑Rotate clockwise
    • SpaceHard drop
    • CHold piece
    • PPause / resume

    快速上手

    • 移动：使用棋盘下方的左右按钮；电脑按 ← / →。
    • 旋转：点击“旋转”；电脑按 ↑。
    • 落底：立即放下当前方块；电脑按空格键。
    • 暂存：先保存当前方块并换出另一个；当前方块落定前只能暂存一次。

    棋盘旁的“落点影子”开关可显示或隐藏预计落点。
